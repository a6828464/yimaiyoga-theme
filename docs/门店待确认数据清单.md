# 门店待确认数据清单（一店一页 · 上线前置）

> 适用版本：yimaiyoga 主题 v1.9.3+（一店一页 `/studio/east`、`/studio/greenland`）
> 原则：**没核对过的值一律留空，前台整块不渲染**。门店页最贵的错误是让人按错的时间、
> 走错的入口白跑一趟——宁可少一块，也不先填一个"大概对"的值。

## 0. 数据落在哪两处

| 位置 | 管什么 | 谁能改 |
|---|---|---|
| 后台「门店」面板（`inc/site-data.php` 的 `studios`） | 店名、面积、地址、电话、经纬度、邮编、营业时间 | YG 在后台改；存 `wp_options` |
| `inc/studio-pages.php` | 地铁 / 停车 / 到店动线（后台没有输入框的项） | 只能改代码（否则后台保存一次就会被抹掉） |

门店页的 8 块内容全部由这两处数据驱动：地址、电话（tel: 可拨）、地铁/停车/到店路线、
该店课程与教练、营业时间、FAQ（3–5 条，随数据增减）、地图占位、预约 CTA（带 `?studio=east`）。

## 1. 上线前置：两个页面必须先存在

`/studio/east` 与 `/studio/greenland` 是「空间与门店」（`/studio`）的**子页面**，
模板靠页面 slug 命中（`page-east.php` / `page-greenland.php`）。中文标题自动生成的 slug
是一串 URL 编码，**必须手动填成英文**，否则会掉到 `index.php` 变成空白页。

| URL | 父级 | 页面 slug（必须） | 页面标题（建议） |
|---|---|---|---|
| `/studio/east/` | 空间与门店 | `east` | 宁波鄞州 · 器械普拉提与空中瑜伽（东部店） |
| `/studio/greenland/` | 空间与门店 | `greenland` | 宁波江北 · 普拉提大器械与体态调整（绿地店） |

建页两种方式，任选其一：

1. **服务器命令行（推荐，slug 不会填错）**
   ```bash
   php wp-content/themes/yimaiyoga/cli/create-studio-pages.php
   ```
   幂等：已存在的页面只报告不覆盖。
2. **后台手动**：页面 → 新建 → 父级选「空间与门店」→ 标题按上表 → 右侧「固定链接」把
   slug 改成 `east` / `greenland` → 发布。

### 2.4 营业时间写法（填 `openingHours` 时）

后台「门店」的营业时间字段按下面格式填，格式不合法会被**清空**（不是拒绝保存）：

```
Mo-Su 09:00-21:30                 # 周一到周日同一时段
Mo-Fr 10:00-21:00,Sa-Su 09:00-21:30   # 周中与周末不同（逗号分段）
```

填好后**不用改模板**，以下四处会自动出现：门店页 hero、门店页「营业时间」块、
门店页 FAQ 第 4 问、JSON-LD 的 `openingHoursSpecification`。

## 3. 填完后的自检（线上）

```bash
# 1) 页面能开、H1 四要素齐全
curl -s https://www.nbyimai.com/studio/east/ | grep -o '<h1>[^<]*</h1>'
# 期望：宁波鄞州 · 器械普拉提与空中瑜伽（东部店）

# 2) 门店实体与 FAQ 标记都在
curl -s https://www.nbyimai.com/studio/east/ | grep -o 'HealthAndBeautyBusiness\|FAQPage\|studio/east#store'

# 3) 营业时间填好后，Schema 里应出现（填之前不应出现）
curl -s https://www.nbyimai.com/studio/east/ | grep -o 'openingHoursSpecification'

# 4) 预约参数生效：门店页 CTA 指向 /booking?studio=east，预约页门店应预选「东部店」
curl -s 'https://www.nbyimai.com/booking?studio=east' | grep -o '<option value="东部店" selected>'
```

Schema 校验：Google Rich Results Test / Schema Markup Validator 粘贴 URL，确认
`HealthAndBeautyBusiness` 与 `FAQPage` 无报错（缺 `geo` 不算错，缺 `openingHoursSpecification` 也不算错）。

## 4. 明确不做的事

- 不为了让 Schema "看起来完整"而编造坐标、营业时间、地铁站或停车政策
- 不在门店页写「待确认」「示例」这类面向内部的占位文案
- 不合并两家店到同一页（一店一页是同城位置词唯一的落地载体）
